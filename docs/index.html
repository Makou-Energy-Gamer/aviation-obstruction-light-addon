航空障害灯
アドオン

建物やタワーに、設定可能な航空障害灯を追加します。

ダウンロード

統合版用 / v1.0.0 / .mcaddon

01

設置方法を選べる

屋上などに置く上置き型と、建物の側面に取り付ける壁面型を収録しています。

02

光り方を調整

明るさを3段階から選び、点滅と常時点灯を切り替えられます。

03

点滅周期を設定

用意された周期から選ぶほか、好みの周期を手動で設定できます。

INSTALLATION

導入方法

  1. ダウンロードした .mcaddon ファイルを開き、Minecraftにインポートします。
  2. 使用するワールドの設定を開きます。
  3. ビヘイビアーパックとリソースパックの両方を有効にします。

ベータAPIや実験的機能を有効にする必要はありません。

SETTINGS

設定方法

設置した航空障害灯を操作すると設定画面が開きます。明るさ、点灯モード、点滅周期を選択してください。近くにつながっている航空障害灯には設定をまとめて反映できます。
